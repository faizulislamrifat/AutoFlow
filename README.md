## 🌟 Overview
**AutoFlow** is an advanced, high-performance Chrome Extension tailored exclusively for **Google Flow** creators. It streamlines repetitive prompting into an intelligent, hands-free automated pipeline—allowing you to queue hundreds of prompts, run batch video generations, handle retries gracefully, and download completed clips automatically with zero manual hassle.

---

## 🚀 Key Features

* ⚡ **One-Click Batch Queueing:** Queue and run multi-prompt video generations automatically.
* 💎 **Cyber-Luxury Side Panel UI:** Clean, modern dashboard built with a professional glassmorphic design.
* 🔄 **Smart Retry & Error Recovery:** Auto-detects pending generation states and retries failed prompts without interrupting your flow.
* 📥 **Automated Downloader:** Fetches and saves completed video assets directly to your local storage.
* 📊 **CSV & Google Sheets Bulk Importer:** Easily paste or upload prompt tables with tags and parameters.
* ✨ **Magic Prompt Enhancer:** Upgrades basic prompts into high-detail cinema-grade Veo prompts.
* 🛡️ **Zero-Error Logging:** Clean isolated console logging designed to stay compliant with Chrome Developer Mode standards.
* 🌐 **Direct Creator Connect:** Instant social links to connect with the author.

## 📥 Installation Guide

1. Clone or download this repository:
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   ```
2. Open Google Chrome and navigate to:
   ```text
   chrome://extensions/
   ```
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** in the top left corner.
5. Select the repository root folder (the folder containing `manifest.json`).
6. Pin **AutoFlow** from the Chrome extensions puzzle menu.

---

## 🎮 How to Use

1. Navigate to [Google Flow](https://flow.google.com) and log in with your account.
2. Click the **AutoFlow** icon to open the side panel dashboard.
3. Paste or type your prompt list (separate each prompt with an empty line).
4. *(Optional)* Add a time-tag at the start of prompts (e.g. `#0:04`) to name output files automatically.
5. Click **Start AutoFlow** (or press `Ctrl + Enter`).
6. Keep the Google Flow tab active while AutoFlow generates and saves your clips.
